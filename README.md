# Image Hash Generator

Author: Jared De Santis  
Platform: Limitless Mobile Applications (LMA)

---

## Overview

Image Hash Generator is a fully client-side Progressive Web Application (PWA) that allows users to generate unique hash values from images directly within their browser.

The application is designed to be:
- Offline capable
- Lightweight
- Secure (no server interaction)
- Installable on desktop and mobile devices

---

## Features

- Drag-and-drop image upload
- Local hash generation
- Copy-to-clipboard functionality
- Offline support via Service Worker
- Installable PWA

---

## Installation

1. Open the app in a modern browser
2. Click "Install" (or "Add to Home Screen")
3. The app will function offline after installation

---

## Technical Notes

- 100% client-side (no backend dependencies)
- Uses browser crypto APIs
- Cached via Service Worker
